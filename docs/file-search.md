# 硬盘文件搜索

主搜索框会在软件结果后显示最多 5 条文件或文件夹，并显示完整路径。点击「更多文件结果」，或直接输入 `f 关键词`，进入文件专页。查询使用本机 Everything 索引，只搜名字，不读取文件正文，也不向翻译服务发送文件搜索关键词。

## 使用方法

| 输入或操作                  | 效果                                                |
| --------------------------- | --------------------------------------------------- |
| `家人`                      | 主框显示软件及最多 5 条文件结果                     |
| `f 家人`                    | 文件专页，最多显示 200 条                           |
| `f 家人 照片`               | 文件名同时匹配两个词                                |
| `f zyx`、`f zhuyuanxin`     | 模糊模式下匹配「朱元欣」等中文名                    |
| `f 家人\ jpg`               | 限定路径包含 `家人\`，名字包含 `jpg`                |
| `f re:^朱元[昊欣].*\.docx$` | 按正则表达式搜索；格式错误或超过 256 字符时提示错误 |
| 回车 / 点击                 | 打开选中的文件或文件夹                              |
| Ctrl+回车 / Ctrl+点击       | 打开所在文件夹并选中该项                            |
| Ctrl+Shift+C                | 复制完整路径，并显示「已复制路径」                  |
| 右键                        | 打开、打开所在文件夹、复制路径                      |

上下方向键或 Tab 切换选中项。在文件专页内，空格用于分隔关键词；双击空格和 Ctrl+Shift+T 不触发翻译。

专页的「模糊 / 精确」「类型」「排序」立即生效并记住选择，返回主搜索框后也沿用这些选择。类型支持多选，点「全部类型」清除筛选；点击「类型」展开或收起时，窗口高度随内容调整。

## 匹配和排序

- 不区分英文大小写；全角、半角输入会归一化。多个词按“同时满足”匹配，普通词只匹配文件名；带路径分隔符或盘符的词匹配完整路径。
- 「精确」指原字包含匹配，并非要求整个文件名完全相同；不做拼音、插字、错字匹配。
- 「模糊」依次优先显示：名称相同、开头相同、包含原字、拼音、中间多出少量字、少量错字。例如「家人」可以带出「家里人」，「朱元昊」可以带出「朱元欣」，原字结果始终在前。
- 「最近修改」仍先显示原字匹配，再显示模糊匹配；每组内部按修改时间从新到旧排列。
- 主框至少输入 1 个中文字符或 2 个其他字符才查询；算式、粘贴附件及其他显式搜索范围不附加文件结果。输入或筛选改变后立即撤下旧行，停顿约 150 ms 再查询，旧响应不会覆盖新结果。

## 设置与排除目录

在设置的「搜索范围」中找到「硬盘文件搜索」：

- 「在主搜索框显示硬盘文件结果」默认开启。关闭后主框不再查文件，仍可用 `f 关键词` 明确进入专页。
- 「不搜索这些文件夹」每行填一个 Windows 路径片段，不区分大小写。例如 `D:\临时文件\`。清空列表表示不排除目录；此设置只影响结果，不删除任何文件。
- 默认排除 Windows、ProgramData、回收站、恢复目录、WindowsApps、AppData，以及 node_modules、.git、Python 和常见应用缓存目录。普通 Program Files 不被整体排除。

功能是主程序内置的，不需要打开插件搜索。软件搜索结果仍在文件结果之前。

## Everything 与本机查询口

本机已经安装带 voidtools 签名的 Everything 1.4.1.1009，程序位于 `C:\Program Files\Everything`，索引服务自动运行。不要重复安装或重新生成查询密码。

- 程序目录的 `Everything.ini` 使用 `app_data=1`；查询配置在 `%APPDATA%\Everything\Everything.ini`。
- 查询口绑定 `127.0.0.1`，使用随机端口及用户名、密码；禁止通过该查询口下载文件。ZTools 只连接本机地址，凭据从配置文件读取，不写入源码、日志或说明。
- Everything 查询进程未运行时，ZTools 在功能开启的启动预热或实际查询中尝试 `Everything.exe -startup`，不打开 Everything 窗口，不申请管理员权限。服务和查询进程不是同一件事：只有索引服务运行而查询进程未运行时，HTTP 查询仍需要启动后者。
- 连接失败会在文件专页显示简短提示。先确认 Everything 已安装、查询进程在运行、只限本机的查询口已启用；不要因此打开公网端口。
- 既有配置备份为相应 ini 的 `.bak-20261112`；插件自带的 Everything 副本已禁用其查询口及管理员启动，避免争用。安装维护脚本为 `scripts/local/install-everything-service.ps1`，卸载参数为 `-Uninstall`；不作为日常搜索操作使用。

查询语法基础参考 [Everything 官方搜索说明](https://www.voidtools.com/support/everything/searching/)，实际界面以本页列出的功能为准。

## 已知边界

- 搜索范围取决于 Everything 已索引的磁盘和目录；不承诺覆盖未索引位置或文件正文。
- 中文名的拼音、插字和错字使用内存名称列表，最多约 10 分钟更新一次；原字查询直接使用当前索引。首次载入该列表时，可能先出现原字结果，后续查询再包含模糊结果。
- 英文插字补查只在专页模糊模式启用，词长 4–16；英文错字补查只支持 5–10 字符词。主框不运行这部分较慢的补查。
- 专页显示前 200 条；候选查询每档最多取 400 条，中文名称缓存上限 30 万项。结果数用于提示继续缩小范围，不是完整磁盘导出；极宽泛查询不能保证列出所有模糊匹配。
- 文件图标按类型绘制，不读取每个文件的系统图标。正则语法由 JavaScript 先校验，再交给 Everything 执行；两者独有的语法不保证兼容。

## 验证与发布

`tests/helpers/fakeEverything.ts` 提供临时、带假凭据的本机索引服务。测试通过 `ZTOOLS_EVERYTHING_INI` 显式指定假配置；测试模式不读取真实 Everything 配置，也不查询真实硬盘索引。Electron 测试使用临时数据目录及隐藏窗口，打开文件、复制路径、右键菜单由模拟处理器接管。

按 `LOCAL-WORKFLOW.md` 执行 `verify.ps1` → `stage.ps1 -SkipVerify` → 切换预览。实际切换前须从托盘正常退出 ZTools；保留关闭后的数据备份，并检查启动路径。Windows 自启项应指向新版本，核对时确认进程没有 MSIX 包身份，避免把虚拟化的注册表视图当成系统实际状态。推送远端仍需用户单独同意。
