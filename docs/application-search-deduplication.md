# 应用搜索去重

应用索引与主框结果共用 `src/shared/applicationIdentity.ts` 的身份规则。不会删除磁盘快捷方式或用户的“本地启动”配置。

## 合并规则

- 同名、同一可执行程序、相同启动设置的重复入口只显示一项；保留扫描中优先的正式快捷方式及其图标，仍通过原 `.lnk` 启动。
- Windows 路径统一大小写、斜杠和外层引号；不同安装目录、版本或 Store 应用标识保持独立。
- 安装补漏扫描按证据排序：优先主程序和安装登记名称；备用启动器只有在**同目录**存在可确认的主程序时才合并。识别产品名加 `Launcher`、`AppLauncher`、`Launch` 后缀，没有针对 Gemini 的特例。找不到主程序时仍保留唯一备用入口。
- 不仅凭名称或图标合并。用户自定义的不同别名、同一个浏览器的不同账户参数、管理员启动、不同工作目录或窗口方式都保留。
- 无法读取或不支持的快捷方式身份保持独立，不猜测其启动参数。因此有些看起来同名的独立入口仍可能同时显示。
- 设置里的应用缓存升级为 v9；首次启动重新扫描，失败保留旧缓存并允许重试，不要求用户删除个人配置。

## 元数据与边界

现有隐藏 PowerShell 扫描进程通过标准输入接收已发现的 `.lnk` 路径，只读取现有文件，不执行程序。最多读取 1800 个快捷方式、元数据阶段最多约 5 秒，之后安装扫描仍保留原有 10 秒预算；调用方总体超时 20 秒。网络快捷方式、MSI advertised、旧虚拟机、shim 等未知行为保守保留。

启动参数、工作目录、窗口方式和 RunAsUser 标志用于生成摘要。普通启动记为 `default`，其他启动设置使用 SHA-256；不把原始参数返回、写入日志或保存进应用缓存。

快捷方式标志依据 Microsoft 的 [Shell Link flags](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-shllink/4d25bbad-09b7-4322-8c0a-521d268481bb) 与 [SHELL_LINK_DATA_FLAGS](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/ne-shlobj_core-shell_link_data_flags)。

## 验证

- 多个虚构品牌与 Gemini 回归样本；来源顺序变化、唯一备用启动器、不同目录/版本/工具、身份读取失败与目标变化。
- 临时目录生成真实 Windows `.lnk`：验证复制快捷方式、不同浏览器账户参数、工作目录、最小化和管理员标志；损坏或缺失项安全跳过。该用例只运行 `-ShortcutMetadataOnly`，不查询真实安装项。
- 隐藏 Electron 测试使用假应用与临时 profile：重复主入口显示一项，不同账户入口显示两项。其他计算、显式翻译与文件折叠行为仍跑原有回归。
- 测试不读写真实 `.ztools`，不启动真实应用、不调用翻译服务、不操作鼠标或前台窗口。
