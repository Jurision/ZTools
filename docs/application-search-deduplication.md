# 应用搜索去重

应用索引与主框结果共用 `src/shared/applicationIdentity.ts` 的安装身份规则，适用于已有和以后新安装的应用，不使用品牌排除名单。不删除磁盘快捷方式或用户的“本地启动”配置。

## 合并规则

- 同一可执行程序、相同启动参数的入口合并为一项，即使来自桌面、开始菜单、安装登记或本地启动，或者名称带有版本号、不同语言、用户自定义名称。
- 不同名称保留为搜索关键词；用任一名称搜索，显示的仍是同一应用。优先保留普通正式快捷方式及其图标，通过原 `.lnk` 启动。
- 工作目录、管理员权限、窗口大小等启动设置不再产生多条应用结果。同名、同一安装但参数不同的启动方式也收进一项；右键“其他启动方式”可选择原快捷方式，参数与权限仍由 Windows 处理。
- 不同安装目录、并存版本、便携副本、Store 应用标识保持独立，不凭相同名称或图标跨安装合并。
- 共用宿主的独立应用保留：例如两个不同网站的 PWA、同一游戏启动器里的不同游戏。它们具有不同名称和不同参数摘要；不能把共用 Chrome 或 Python 的所有项目当成一个应用。
- 安装补漏发现某个可执行文件已由快捷方式覆盖时，不再追加裸 EXE 入口。备用启动器只有在同目录存在可确认的主程序时才合并；识别产品名加 `Launcher`、`AppLauncher`、`Launch` 后缀，没有针对某个品牌的特例。
- Windows 路径统一大小写、斜杠和外层引号。无法确认目标或参数的特殊快捷方式保留原启动动作，不凭猜测隐藏独立应用。
- 应用缓存升级为 v11，首次启动自动重建；以后正常索引更新也执行同样规则。扫描失败保留旧缓存并允许重试，无须用户逐个排除或删除个人配置。

## 元数据与边界

隐藏 PowerShell 进程通过标准输入接收快捷方式路径与原生解析的目标，以显式 UTF-8 解码，支持中文和空格路径。WScript 对 ID-list 快捷方式返回空目标时使用原生扫描结果。只读取文件，不执行程序；最多读取 1800 个快捷方式，元数据阶段约 5 秒、安装扫描另有 30 秒预算，总体超时 40 秒。

参数单独生成摘要，用来区分宿主中的独立应用；参数、工作目录、窗口方式和管理员标志另生成完整摘要，用来保留启动动作。普通启动记为 `default`，其他使用 SHA-256，不把原始参数返回、写入日志或保存进应用缓存。网络快捷方式、MSI advertised、旧虚拟机与 shim 等特殊行为保守处理。

快捷方式标志依据 Microsoft 的 [Shell Link flags](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-shllink/4d25bbad-09b7-4322-8c0a-521d268481bb) 与 [SHELL_LINK_DATA_FLAGS](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/ne-shlobj_core-shell_link_data_flags)。

## 验证

- 100 个虚构产品、400 个不同来源和名称入口，正序、逆序、轮换来源顺序均归并为 100 个应用，别名和启动动作保留，重复归并结果不变。
- 覆盖不同安装、不同版本、独立宿主应用、同名启动配置、新应用刷新、目标变化、元数据缺失和安装补漏。
- 临时目录生成真实 Windows 快捷方式：中文与空格路径、不同参数、工作目录、最小化、管理员、空 WScript 目标；缺失 emoji 路径和损坏项安全跳过。只读测试夹具，不查询真实安装项。
- 隐藏 Electron 使用假应用与临时 profile，验证一个应用一个结果、别名仍能搜索、右键可启动指定变体、两个版本及独立宿主应用不误并、刷新后新应用自动去重。
- 自动化测试不读写真实 `.ztools`，不启动真实应用、不调用翻译服务、不操作鼠标或前台窗口。计算、显式翻译与文件折叠仍运行原有回归。
