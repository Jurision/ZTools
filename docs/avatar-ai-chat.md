# 头像进入 AI 对话

- 主搜索框有文字：点击右侧头像，进入官方「AI助手」插件的新对话，并提交当前文字。粘贴的文字块及追加问题一并带入。
- 主搜索框为空或只有空格：点击头像仍进入设置。
- 插件运行时：头像仍打开原来的插件菜单。输入法组字未完成时不发送。
- 单纯输入、应用搜索、计算、展开文件结果不会触发 AI 请求；翻译仍走原来的显式快捷键。
- 插件未安装或启动失败会保留原文并给出提示。快速重复点击不会重复启动。

配置：在插件市场安装「AI助手」（插件 ID `ai-helper`）；设置 → 提供商 → AI 添加 DeepSeek，协议选 OpenAI Chat Completions、地址 `https://api.deepseek.com`，自行填写密钥并从 API 获取模型。本机选择 `deepseek-flash`。密钥只存在用户本机数据库，不在本仓库。后续模型变化请重新获取模型列表。

AI助手支持连续追问、切换模型及本地对话历史；只有明确提交的内容及该对话历史会交给所选提供商。头像每次从搜索页进入时开新对话。此功能不改变翻译提供商。

测试使用临时 profile、模拟 HTTP 服务和假密钥。`tests/e2e/avatar-ai-chat.spec.ts` 默认使用协议测试插件；设置 `ZTOOLS_TEST_AI_HELPER_ZIP` 可额外对已下载的官方原版 ZIP 运行同一验收，不访问真实账号或外部 AI。官方插件包不提交进仓库。
