# 主搜索框快速运算与快速翻译

本地功能分支：`codex/quick-calculate-translate`。只生成待切换版本，不改变当前运行程序、自启项或代理。

## 使用与设置

- 输入 `200000*1.5`、`(3+4)×2` 等完整算式，第一项直接显示结果；回车进入详细稿纸，Ctrl+回车或点击复制数值，并显示“已复制”。显示保留原计算稿纸的千分位和 32 位有效数字规则；复制不带千分位逗号。单独数字、未完成算式和软件名继续正常搜索。
- 支持 `+ - * / ( ) % ^`、小数和对应全角字符。百分号既支持百分比，也兼容原计算引擎的二元取模；安全解析器不执行代码。表达式最多 512 字符、200 个令牌、32 层嵌套，幂和数值指数限制为 1000；超限、不完整或无穷结果不显示计算项。
- **打字时不自动翻译。** 快速连按两下空格（400ms 内，第二下不会多打一个空格）或按 Ctrl+Shift+T，才翻译当前输入；之后修改文字，旧译文自动消失。自己粘贴进空搜索框的文字块仍自动翻译（见下文“粘贴文本块”）。
- 翻译项在应用结果后面，方向为中文→英文、英文→中文。**有道和 OpenAI 同时请求，各显示一行**（标有服务名），谁先返回谁先显示；只列出已填密钥的服务，“用于搜索翻译”所选的服务排在最前。用方向键选中某一行回车，或点击，复制该行译文。两个服务都没填密钥时只显示一行“回车打开翻译设置”。
- 设置 → 常规 → 默认搜索范围：**输入时自动计算**、**粘贴文字时自动翻译**，默认都开；保存后立即生效。它们不依赖插件搜索开关。双击空格和 Ctrl+Shift+T 不受这两个开关影响。
- 设置 → 提供商 → 翻译 → 搜索翻译：有道填 AppKey/AppSecret，OpenAI 兼容填 Base URL/API Key/模型。填好密钥的服务都会参与搜索翻译；“保存并用于搜索翻译”只决定哪一行排在最前，未选择时有道在前。该选择保存在现有提供商框架的 `params.search-translation.providerId`，不覆盖其他插件使用的默认翻译提供商。
- 密钥只保存在本机已有提供商数据库，输入框遮蔽秘密字段；代码、日志、测试和提交不含真实密钥。Base URL 支持 HTTPS 或本机 localhost HTTP，不在 URL 中放密钥。网络通过 Electron `net.fetch` 使用系统代理，不修改 Clash；约 5 秒超时，包括读取响应正文。

## 到计算稿纸接着算

计算结果行上直接按回车（或按住 Ctrl 点击），会打开计算稿纸插件，把当前算式作为稿纸最后一行带进去，之后在稿纸里继续多步计算并自动保存。优先使用本地增强版 `calculation-paper-next`，没有时用原版 `calculation-paper`；两者都没装时结果行提示“未找到计算稿纸插件”。Ctrl+回车（macOS 为 Command+回车）或普通点击仍可复制结果；稿纸编辑器内部的 Enter 行为不变。

## 输入什么时候会发送

打字内容只在双击空格或 Ctrl+Shift+T 时发送（两个服务各一次）；显式触发跳过下面的软件名/缩写规则，但网址、路径和疑似密钥仍拦截。下面是原先打字自动翻译用的规则；打字已不再自动发送，这些规则仅保留在策略代码和测试里作参考。

先通过下列拦截检查，再接受 **3 类**输入：

1. 含中文的自然文本；但 4 个汉字以内且本地应用搜索有命中时视为搜软件（如“网易”“腾讯会议”），不自动发送。
2. 由英文字母和空格组成的句子（至少两个词，可带常见英文标点）。
3. 至少 3 个英文字母的单词，并且本地应用搜索没有任何命中。

自动拦截 **7 类**：

1. 已知软件名称、已安装软件的完整名称；英文单词有软件匹配也不发。
2. 全大写英文缩写，例如 API、CPU。
3. 数字、算式、运算符和带数字的软件名，例如 123、2+、7zip、win11。
4. 路径、网址、邮箱、显式指令前缀 `>`。
5. 含 password/token/secret/API key/密码/密钥/验证码等标记的输入，混合大小写令牌、25 字母以上连续长串及数字/特殊符号凭据形态。
6. 空输入、短于 3 字母的孤立英文词、超过 256 字符的输入，以及不在支持字符集内的内容（含数字的中文句子也保守拦截）。
7. 自动粘贴的剪贴板内容、恢复的上次匹配文本、图片/文件附件、插件子输入框，以及关闭自动翻译时的输入。

## 粘贴文本块

用户自己在空搜索框里按 Ctrl+V 粘贴（或用 Ctrl+F 把已输入文本转成文本块）产生的文本块，在搜索框没有再输入其他文字时自动翻译。粘贴的是成段文字，规则与打字不同：不套用软件名规则，允许数字和标点，上限 2000 字符；仍拦截网址、邮箱、路径、含密码/密钥等标记的文本，以及任何字母数字混合 8 位以上或 25 位以上编码串形态的词（疑似凭据）。“复制后自动粘贴”带入的剪贴板内容和恢复的上次匹配文本不会自动发送，仍可按 Ctrl+Shift+T 手动翻译。

测试样例表明确覆盖 **8 个可发送样例**和 **27 个不发送样例**，并另测已安装应用名称、模糊匹配和显式触发边界。样例数不是所有可能输入的总数。

- 停止打字 400ms 后才发送；新输入立即作废旧请求，旧响应不会显示或写入缓存。
- 成功结果仅在内存缓存，最多 32 条；相同规范化短语在等待、请求中或仍在缓存时不会重复请求。更换服务/密钥会清空缓存；错误不缓存；重启后缓存消失。不会把输入或译文写入持久化缓存。
- Ctrl+Shift+T 保留，立即走同一个已选服务；即使自动翻译关闭也可用。它允许显式翻译软件名、缩写和短词，但仍拦截路径、凭据形态和超限输入。
- 软件名和敏感串识别是保守规则，不可能辨认所有未知软件缩写或自然语言形式的秘密。不要输入不愿发送给所选服务的敏感内容；可关闭自动翻译，仅用显式快捷键。

## 单词音标与释义的真实限制

有道官方 2024-04-23 公告说明，标准文本翻译 API 已移除 `basic`、`phonetic`、`explains` 等词典字段，需另行联系商务开通词典服务。本实现解析实际返回的兼容字段；没有返回时显示“服务未返回音标或词典释义”，不会伪造，也不会自动追加另一笔词典请求。

OpenAI 兼容渠道针对单词请求结构化音标和常用释义，兼容普通文本返回；模型输出不是权威词典数据。详情与协议来源见 [翻译提供商协议](translation-provider-protocol.md)。因此，仅有标准有道文本翻译密钥时，“保证每个单词都有音标和释义”无法实现。

## 验证与交付

测试全部使用临时数据目录、隐藏源码 Electron 和模拟翻译服务。复制与启动交互在新 E2E 中被替身拦截，不改用户剪贴板、不启动应用、不发送真实翻译请求。六个验收算式另与缓存的原计算稿纸程序实际渲染结果比较，不读取真实个人稿纸数据库。

按 `verify.ps1` → `stage.ps1 -SkipVerify` → `switch-release.ps1`（默认 Preview）交付。切换和自启不属于本任务。
