# 应用安装清单与独立启动入口

桌面/开始菜单快捷方式只是发现应用的一个来源，不再是已经收录应用的唯一生命期依据。

## 来源与移除规则

| 来源                             | 如何发现/保留                                                                                                                       | 何时移除                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Windows 普通安装                 | App Paths、卸载注册信息、用户 Programs 目录补查；已验证的启动快捷方式复制到 ZTools 私有目录，保留参数、工作目录、提升权限等原始字节 | 对应安装注册消失或目标文件消失；同路径重新注册的有效安装重新接纳             |
| 应用宝 Android                   | 只读 `Tencent/Androws/db/InstalledApp.db` 的公开安装字段；以引擎、包名区分独立应用；从安装注册解析引擎位置                          | `kUnInstallSuccess`，安装行移除，或引擎卸载；已知安装在更新/卸载失败期间保留 |
| Windows 商店/UWP                 | 继续使用当前用户包注册枚举与包变化通知                                                                                              | 包卸载，不依赖 `.lnk`                                                        |
| MSI 通告快捷方式                 | 原样保存 `.lnk`，通过 Windows Installer 查询产品是否仍安装，不触发修复或安装                                                        | 产品不再为当前用户安装                                                       |
| Chrome/Edge 网页应用             | 保存原启动参数，重新读取子应用安装目录的存在性，支持旧 `_crx_` 目录和 `Manifest Resources` 布局                                     | 子应用安装目录消失，浏览器本身仍在也不能保留旧子应用                         |
| Steam 游戏                       | 公共的 `Steam App <id>` 安装注册，使用对应游戏启动协议                                                                              | 游戏安装注册移除                                                             |
| 已识别的便携程序、批处理启动入口 | 保留已验证启动副本；不扫描整个硬盘                                                                                                  | 实际目标文件消失                                                             |

应用宝状态值依据本机应用宝随附 `yyb-jsbridge` 的 `InstallState` 枚举核对：1003 为安装成功、2003 为卸载成功。当前适配 VBox Android 引擎；PCGame 行不当作 Android 应用启动，普通 Windows 程序走 Windows 安装来源。读取在 Worker 中执行，5 秒超时，SQLite 只读并读取 WAL 中已提交的变更。不访问账号、聊天、阅读内容或登录凭据，不启动 Android 引擎。

MSI 使用只读的 [MsiGetShortcutTarget](https://learn.microsoft.com/en-us/windows/win32/msi/installer-function-reference) 和 [MsiQueryProductState](https://learn.microsoft.com/en-us/windows/win32/api/msi/nf-msi-msiqueryproductstatew)。不会使用可能触发重装的 `Win32_Product` 或 `MsiProvideComponent`。

## 刷新、持久化与边界

- 私有启动入口及清单在 ZTools 数据根目录的 `application-launchers`；修改桌面或开始菜单名称仍作为别名保留。隐藏应用的原路径别名也保留。
- 不创建新的桌面或开始菜单图标，不修改安装器注册，不联网。首次启用缓存版本 16 时自动完整重扫。
- 沿用启动扫描、快捷方式变化通知、商店包通知和约 5 分钟安装对账。对账包含应用宝 DB/WAL 时间戳和已保留目标的存在性，因此仅在应用宝内安装/卸载也会触发刷新。不是每次按键都扫描安装清单。
- 任一来源超时、损坏或读取失败，当前扫描标记不完整，继续保留上一份完整搜索缓存。失败不能被解释为卸载。
- 未注册、任意目录中、从未被 ZTools 识别的便携应用，仍需从“本地启动”添加。未知第三方启动器的内部子应用清单需要相应适配；不会声称已覆盖任意安装器/模拟器。
- 无法恢复启用本功能前已经删除、且没有任何安装记录的孤立入口。本机静读天下有应用宝安装记录，所以可以直接恢复发现。

## 验证

专项单测使用临时目录与假安装清单，覆盖无快捷方式安装发现、快捷方式删除、卸载、更新状态、同名多安装、不同参数、数据库失败保留、WAL 更新、便携程序移除、协议游戏及脚本入口。

源码 Electron 隔离测试使用真正的 Windows Shell `.lnk` 写入/读取和 SQLite WAL 数据库，检查删除原始快捷方式后参数/工作目录不变，以及卸载后条目消失。测试窗口保持隐藏、不注册全局快捷键、不使用真实 `.ztools`，不启动测试应用。
