# Local iteration plan

> 历史计划：截至 2026-11-12 的完成状态、剩余需求及优先级以 [需求进度](docs/requirements-status.md) 为准。下文保留当时的范围与验证记录，不代表仍待开发。

Baseline: upstream v3.2.0. Branch: codex/local-workflow-search-paper.
Scope authorized 2026-11-04: reproducible isolated development workflow, default application-only search, multi-paper calculator with automatic saving. Window dragging/resizing remains backlog.

1. Build a dedicated development profile, never point tests at ~/.ztools. Disable hooks/global shortcuts, auto-start, updater and foreground activation in background test mode. Provide verification/build/stage/backup/rollback commands with checked paths.
2. Default search to applications. Exclude files/system/plugin recommendations unless explicitly requested; allow restoration/configuration and explicit plugin access. Hide Global Flags and Get Help by default. Preserve pinned super-panel actions. Explicit translation entry is part of search UX, never global key registration.
3. Implement an original local calculation-paper plugin: sidebar ordered by creation time, Ctrl+N/date titles, debounced persistence with flush on exit/blur, update same paper, preserve/import legacy paper snapshots without deletion. Use isolated fixtures for tests; do not copy proprietary uTools bundle.
4. Review actual diffs. Run unit tests, typechecks and required source-Electron E2E under isolated hidden profile, including new paper/reopen/edit persistence and search filtering. Build a reviewable artifact only after checks.
5. Keep running installed ZTools untouched. Stage local release and rollback material; foreground restart/cutover occurs separately after notifying user. No upstream publication/merge in this local workflow.

Local delivery is the current lane. Record status and validation here; prepare a PR-quality local summary rather than publishing unrequested repository messages.
