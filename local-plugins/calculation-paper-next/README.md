# 计算稿纸 · 时间记录

独立实现的本地 ZTools 插件，不覆盖现有 `calculation-paper` 插件。无网络请求、无鼠标钩子、不读取其他插件数据库。

## 操作

- 左侧按创建时间浏览，最新稿纸在前。
- “新稿纸”或 Ctrl+N；未编辑的空白稿纸会复用。
- 停止编辑 500ms 后自动保存；切换、窗口失焦、插件退出时立即写入。
- 编辑历史稿纸更新同一记录；不会生成重复快照。
- 每行有算式、结果和备注。Enter 转到下一行；结果旁图标复制数值。
- 标题右侧可修改名称。备份导出所有内容（包括保存失败时仍在内存中的内容）。

支持四则运算（包括 x/X 乘号）、括号、右结合幂、百分比及常用数学函数；不执行 JavaScript。使用标准浮点运算，不适合作为精确财务结算依据。普通算式支持千位分隔符，例如 `1,000+200`；函数内逗号始终分隔参数，例如 `sum(1,200)` 是 201，函数参数中的数字不要使用千位分隔符。

## 原数据保护

首次安装使用独立插件数据库，旧版稿纸不受影响。点击“导入”选择 JSON 数组或 `{ "papers": [...] }`，每项接受旧版 `{ "_id": "paper/时间戳", "label": "名称", "calcList": [{ "expression": "1+2", "remark": "备注" }] }` 格式。导入生成新记录，保留来源标识去重，不修改原文件或旧数据库。

当前 UI 不提供整份稿纸删除；避免在初期迭代中误删历史。行删除属于显式编辑，会自动保存。

保存失败会保留脏数据并显示错误，不伪装成成功。版本冲突不会覆盖另一个写入者，可导出备份后重新打开。工作流默认单实例使用；异常进程终止可能丢失最后 500ms 尚未落盘的更改。

## 开发验证

`node --test local-plugins/calculation-paper-next/core.test.cjs`

该命令只使用内存数据库。宿主 Electron E2E 由根项目执行，必须使用隔离数据目录，不得连接真实 `~/.ztools`。页面需要 `window.ztools.db`，普通浏览器直接打开会显示不可编辑状态，不退回不明位置保存。

重要选择器：`#new-paper`、`#paper-list .paper-item`、`.expression`、`.remark`、`.result`、`#save-state`、`#retry-save`、`#import-file`。插件入口 feature code：`paper`。
